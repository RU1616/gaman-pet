# がまんペット

がまんした食べ物を記録すると、そのカロリーの分だけ動物が太っていくダイエット応援アプリです。

## しくみ

- **太る速さ** ＝ がまんしたカロリー ÷ その動物（おとな）が1日に必要なカロリー
  - 結果は「ごはん何日分か」になり、これがレベル（太り具合）を決めます。
  - 例：ショートケーキ1個（350kcal）は、ハムスターならごはん約11.7日分、ゾウなら1日分の0.6%。
- **レベル**は全10段階。ごはん 0.1 / 0.5 / 1 / 3 / 7 / 14 / 30 / 100 / 365 日分で上がります。
- あげたカロリーは動物ごとに別々に数えます（途中で交代しても、それまでの分は残ります）。
- **のみもの計算機**：100mlあたりのカロリー × 飲む量(ml) ÷ 100

| 動物 | 1日に必要なカロリー | 想定している個体 |
|---|---|---|
| ハムスター | 約30 kcal | ゴールデンハムスター 約120g |
| ネコ | 約240 kcal | 体重4kg |
| イヌ | 約630 kcal | 体重10kg（柴犬くらい） |
| ブタ | 約5,300 kcal | 体重200kg |
| ゾウ | 約58,000 kcal | アジアゾウ 体重3,000kg |

計算式と出典は、アプリの「どうぶつ」画面の下にある「必要カロリーの計算のしかた」に載せています。

## ファイル構成

| ファイル | 中身 |
|---|---|
| `index.html` | 画面の骨組み |
| `css/style.css` | 見た目（色・大きさは先頭の `:root` で変えられます） |
| `js/data-animals.js` | 動物の必要カロリー・セリフ・レベルの条件 |
| `js/data-foods.js` | たべもの・のみものの一覧 |
| `js/logic.js` | 検索、レベル計算、表示の整形 |
| `js/store.js` | 記録の保存（ブラウザの localStorage） |
| `js/art.js` | 動物のイラスト（SVGをコードで描いています） |
| `js/app.js` | 画面の動き |

## よくある変更

- **食べ物を足す**：`js/data-foods.js` の表に1行追加します。
  `['名前', カロリー, '量の目安', '絵文字', '検索用のよみ・別名']`
- **飲み物を足す**：同じファイルの `DRINK_TABLE` に1行追加します。
  `['名前', 100mlあたりのkcal, 'サイズの種類', '絵文字', '検索用のよみ・別名']`
- **太る速さを変える**：`js/data-animals.js` の `dailyKcal`（動物ごと）か `LEVELS`（レベルの条件）を書きかえます。

## 注意

- カロリーは食品成分表や一般的な栄養情報をもとにした**目安**です。商品・お店・量で変わるので、入力画面でいつでも数字を直せます。
- 記録はそのブラウザの中だけに保存されます。別のブラウザや端末には引き継がれません。
- 食事を抜くためではなく、「食べすぎ・間食をひとつがまんできた」を数えるためのアプリです。
